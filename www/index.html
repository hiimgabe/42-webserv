About Webserv

Webserv is about developing a simple web server entirely from scratch using C++. The main goal of this project is to deepen the understanding of low-level network programming and server implementation. The core of it lies in socket programming. The server handles client connections directly following c++98 standards.
Webserv supports HTTP methods GET, POST and DELETE aswell as Commmon Gateway Interface(CGI) scripts to generate dynamic content.
Webserv takes inspiration in Nginx by allowing the user to define server behaviour through a .conf file.
