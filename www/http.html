HTTP Protocol

HTTP stands for HyperText Transfer Protocol. It is the foundation of data communication on the World Wide Web.

What is HTTP?

HTTP is a protocol used by web browsers and web servers to communicate.
When you type a URL in your browser and press enter, your browser sends an HTTP request to the server, which then responds with the requested content (like a webpage, image, or video).

Key Features

  • Request/Response Model: The client (usually a browser) sends an HTTP request, and the server replies with an HTTP response.
  • Stateless: Each request is independent. The server does not retain information about past requests unless managed by cookies or session tracking.
  • Text-Based: HTTP messages are readable by humans and are structured in a plain-text format.

Common HTTP Methods

  • GET Retrieve data from the server.
  • POST Submit data to be processed (e.g., from a form).
  • DELETE Remove data.

HTTP Status Codes

  • 1xx Informational: The request was received, continuing process.
  • 2xx Success: The request was successfully received, understood, and accepted.
  • 3xx Redirection: Further action needs to be taken to complete the request.
  • 4xx Client Error: The request contains bad syntax or cannot be fulfilled.
  • 5xx Server Error: The server failed to fulfill a valid request.
