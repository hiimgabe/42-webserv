Common Gateway Interface

CGI (Common Gateway Interface) is a standard protocol used to interface external programs with web servers to generate dynamic content.

What is CGI?

CGI allows the web server to pass user requests (from forms, URLs, etc.) to an external application (e.g., CPP, Python), and then return the application's output as part of the web response.

How It Works

  1. A client (usually a browser) sends an HTTP request to the server.
  2. The server identifies a request meant for a CGI script (usually from a specific URL path or file extension).
  3. The server executes the script as a separate process and passes request data to it using environment variables and standard input (stdin).
  4. The CGI program processes the data and returns output through standard output (stdout), including HTTP headers and body.
  5. The server sends this output back to the client as the HTTP response.

Environment Variables in CGI

Common environment variables passed by the server to a CGI script include:

  • REQUEST_METHOD: The HTTP method used (GET, POST, etc.)
  • QUERY_STRING: Data passed in the URL for GET requests
  • CONTENT_LENGTH: The length of the data for POST requests
  • CONTENT_TYPE: MIME type of submitted data
  • SCRIPT_NAME: Path to the CGI script

Example CGI Script (in Python)

#!/usr/bin/env python3
print("Content-Type: text/html")
print()
print("<html><body>Hello from Python CGI!</body></html>")

Advantages of CGI

  • Language Flexibility: CGI scripts can be written in any language that can read from standard input and write to standard output (e.g., CPP, Python).
  • Simplicity: No need for additional modules or frameworks—just place the script and set permissions.
  • Separation of Concerns: Keeps business logic separate from web server configuration.
  • Educational Value: Great for learning how HTTP, environment variables, and server-side processing work at a low level.
